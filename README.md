# Excel and Data Analysis

Interactive English-language Excel course.

## Structure

- `index.html` — interactive textbook shell
- `config/course.json` — course schedule and source map
- `lessons/` — lesson content in Markdown
- `materials/` — practical files
- `tests/` — assessment files

## Course

1. Excel Foundations: Reliable Workbooks and Modern Formulas
2. Power Query: Data Import, Cleaning and Transformation
3. Data Model, PivotTables, Power Pivot and DAX
4. What-If Analysis and Model Validation + Midterm Test
5. Data Analysis, Statistics and Forecasting in Excel
6. VBA and Excel Automation
7. Interactive Dashboards and Automated Reporting
8. Final Assessment

Lessons 1 and 2 are populated. Lessons 3–7 and the assessment files are placeholders for later content.
